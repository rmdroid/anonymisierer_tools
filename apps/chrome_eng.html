What the extension does

Paste Guard

Checks text in supported AI chats before pasting and anonymizes it in the intended flow.

Server connection

Can use KI-Anonymisierer Server for detection, so browser workstations share the same central service.

Rule-based detection

Names, addresses, contact details and identifiers, locally in the browser.

Gemini Nano optional

Chrome’s local AI as a second detection layer when device and browser support it.

Visible categories

Detected areas stay traceable instead of a black box.

Light and dark

Compact interface for different browser setups.

Good to know

Paste Guard works in supported AI chats, not on every website. With a server connection, text is sent to your own server for analysis. The extension stays free; a shared company server has its own license terms.

Frequently asked questions

Is the extension really free?

Yes, you install it for free from the Chrome Web Store.

Does Chrome replace the Mac or Windows app?

No. Chrome is for text workflows in the browser. The desktop apps add system-wide shortcuts, and on Mac also images and restoration.

What is Gemini Nano?

Chrome’s local AI. If your device supports it, the extension can use it in addition to rule-based detection. You can switch it on or off in the settings.

What does the server connection change?

Detection then runs on your KI-Anonymisierer Server instead of only in the browser. Useful when rules and custom terms should be maintained centrally.
