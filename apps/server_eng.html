How client and server work together.

  1. Run the server

    Start the Docker service in your network, choose detection modules and maintain custom terms.

  2. Connect clients

    Enter server address and access key in the Windows client. The key is stored encrypted with Windows DPAPI.

  3. Copy and consent

    By default, the client asks before copied text is sent to the server.

  4. Confirm and replace

    The client shows the number of matches. Only your confirmation replaces them with placeholders.

What server and client bring

Self-hosted

A Docker service in your infrastructure, not in someone else’s cloud.

Rules plus GLiNER

Rule-based detection, optionally extended by a specialized model, without a chatbot interface.

Maintained centrally

Detection modules and custom terms in a browser interface, including test texts.

Open API

Returns matches with category and position, for the Windows client, Chrome and your own integrations.

Windows client

Tray app without its own AI models, asking before sending and before replacing. Optional Safeguard. Coming soon to the Microsoft Store.

No models per PC

Models are installed once on the server instead of on every workstation.

Transparency on data processing

In server mode, the original text is sent to your configured server for analysis. According to the server documentation, no plain text is stored there. Operating logs, upstream components and a correctly configured HTTPS connection must be considered in your own operation. The client currently processes text and does not offer restoration.

Frequently asked questions

Do 200 workstations need 200 AI installations?

No. With the server, detection is provided centrally. The required size depends on text volume, response times and concurrent requests.

Does the API return fully anonymized text?

No. The API returns matches with category and position. The connected client creates the placeholders.

What does the server cost?

Local single-seat use is free. For network and multi-user operation, licenses are based on the number of users, for example €990 per year for 25 users plus VAT. Other tiers and perpetual licenses on request. The server EULA applies.

Does the client install Docker or the server?

No. A running KI-Anonymisierer Server is required, locally on the same PC or in the network.
