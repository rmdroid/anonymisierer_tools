Copy. Shortcut. Keep working.

  1. CtrlC

    Copy text

    Select text in any application and copy it as usual.

  2. Ctrl⇧A

    Anonymize

    Detected details are replaced with placeholders such as [Person 1] or [Email 1].

  3. CtrlV

    Review and paste

    The editor shows original and result side by side. The final check is yours.

Three layers, one fast workflow

Regex

Email addresses, phone numbers, dates, IBANs and other identifiers. Define or exclude your own terms.

NER, built in

Finds people, places and organizations, without internet access or extra software.

Local AI, optional

Set up a small model in the app or connect Ollama or LM Studio.

Tray, editor, shortcut

Click the tray icon for the editor, right-click for quick actions.

Safeguard

If you choose, checks the clipboard locally for sensitive details and flags matches.

Restoration

Map placeholders from the last session back, held in memory for five minutes at most.

The real app (German interface)

Limits

The Windows app processes text, not images or screenshots. The small additional AI is an experimental add-on and does not guarantee complete detection. Setup downloads require an internet connection. The app interface is currently German only.

Frequently asked questions

Is my text uploaded?

No. Anonymization runs on your PC, without an anonymization server.

Do I need Ollama or LM Studio?

No. Regex and NER are built in. For the optional AI check, set up a small model in the app or connect an existing installation.

How is it different from the Windows client?

The Windows app detects locally on the PC. The Windows client uses a central KI-Anonymisierer Server instead and is meant for teams.

Is the app available in English?

Not yet. The app interface is currently German only.
