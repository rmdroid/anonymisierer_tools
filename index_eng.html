Good to know

Honest answers.

Does my text leave my computer?

Not with the apps for Mac, iPhone, iPad and Windows, or the Chrome extension without a server connection: detection runs on your device. In server mode, text is sent to your self-hosted server for analysis.

Does the software detect every sensitive detail?

No automatic detection is complete. KI-Anonymisierer supports the review; checking before you share remains essential.

Does this make my use automatically GDPR-compliant?

No software can promise that across the board. KI-Anonymisierer reduces personal data before text is shared. The legal assessment of your use stays with you and your data protection advisor.

Do we need a server for several workstations?

Not necessarily. Each workstation can use its own app. The server pays off when you want to maintain detection and custom terms centrally.

How large does the server need to be?

That depends on text volume, response times and concurrent requests. In the pilot, we work out together what your setup needs.
