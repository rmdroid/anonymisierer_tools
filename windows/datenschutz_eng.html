General information

The following information provides a simple overview of what happens to your personal data when you visit this website. This website was developed with GDPR requirements in mind.

2. Data collection on this website

This website does not use cookies. No user accounts are created and no marketing cookies are set. If you use the Updates / Newsletter form, the data you enter is sent via an external webhook service to Robert Meyer to process your request.

3. External services

Google Fonts are loaded to display the website. Umami is used for anonymized reach measurement. If you submit the update form, the entered data is sent to an external webhook endpoint. The privacy policies of the respective providers also apply to these external services.
