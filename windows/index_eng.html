FAQ

Good to know.

Does my text leave the PC?

Anonymization runs locally on your Windows computer. No anonymization server is required. Anything you then paste into other applications is processed under their terms.

Do I need the optional AI?

No. Regex and the built-in NER keep working without it. The extra layer is experimental. You can set up a small model in the app, or connect Ollama or LM Studio. Setup downloads need an internet connection.

What does Safeguard check?

Safeguard can check the clipboard locally for sensitive details and point out what it finds. You still decide what to share.

How does restoration work?

When restoration is enabled, placeholders from the latest session can be mapped back. The mapping is kept in memory for no more than five minutes. After that, restoration is no longer possible.

Are images or screenshots processed?

The current Windows version processes text. Image and screenshot features from the Apple apps are not automatically part of the Windows app.
