Gut zu wissen

Ehrliche Antworten.

Verlässt mein Text den Rechner?

Bei den Apps für Mac, iPhone, iPad und Windows sowie in der Chrome-Erweiterung ohne Serveranbindung nicht: Die Erkennung läuft auf Ihrem Gerät. Im Servermodus wird der Text zur Analyse an Ihren selbst betriebenen Server übertragen.

Erkennt die Software alle sensiblen Angaben?

Keine automatische Erkennung ist vollständig. KI-Anonymisierer unterstützt die Prüfung, die Kontrolle vor der Weitergabe bleibt entscheidend.

Ist die Nutzung damit automatisch DSGVO-konform?

Das kann keine Software pauschal zusagen. KI-Anonymisierer reduziert personenbezogene Angaben, bevor Texte weitergegeben werden. Die rechtliche Bewertung Ihres Einsatzes bleibt bei Ihnen und Ihrer Datenschutzberatung.

Brauchen wir für mehrere Arbeitsplätze einen Server?

Nicht zwingend. Jeder Arbeitsplatz kann eine eigene App nutzen. Der Server lohnt sich, wenn Sie Erkennung und eigene Begriffe zentral pflegen möchten.

Wie groß muss der Server sein?

Das hängt von Textmengen, Antwortzeiten und gleichzeitigen Anfragen ab. Im Pilot ermitteln wir gemeinsam, was Ihr Einsatz braucht.
